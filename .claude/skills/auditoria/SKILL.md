# Auditoría de las 4 C

Corres la auditoría de las 4 C sobre el proyecto actual. Lees (nunca escribes) el manual de operación, la memoria, las skills, las conexiones, las decisiones y las referencias. Puntúas cada C sobre 25. Muestras fortalezas y los 3 huecos de mayor impacto, con el comando concreto del siguiente paso.

**El alcance es estructural: "¿está bien construido el AIOS?"** No es un planeador de capacidades (eso es la skill de subir-nivel). La auditoría responde: ¿están en buena forma los archivos, carpetas, registros y conexiones?

## Las 4 C (25 puntos cada una = 100)

| Capa | Test |
|---|---|
| **Contexto** | Conoce el negocio: identidad, equipo, voz, decisiones, referencias |
| **Conexiones** | Alcanza tus cosas: MCPs, integraciones, fuentes de datos |
| **Capacidades** | Sabe hacer trabajo: skills + agentes |
| **Cadencia** | Corre sin que se lo pidan: rutinas, automatizaciones, hábitos recurrentes |

## Cómo puntuar

**Contexto (25):** manual de operación (5), identidad/voz (5), memoria persistente (5), documentos de referencia (5), decisiones registradas (5).

**Conexiones (25):** cobertura de dominios clave (10), guía de referencia presente (5), conexiones al día (5), `conexiones.md` documentado (3), balance entre leer y escribir (2).

**Capacidades (25):** 3+ skills (10), 1+ skill hecha por ti (10), 1+ agente (5).

**Cadencia (25):** 1+ rutina recurrente (10), señal de actividad reciente (10), carpeta de plantillas (5).

## Formato del reporte

```
# Auditoría AIOS: {fecha}
**Puntaje: {total}/100** ({etapa})

## Tablero
[barras y etiquetas de cada C]

## Fortalezas
[1-3 viñetas]

## Top 3 huecos (ordenados por impacto)
[pasos concretos]

## Siguiente sugerido: [la acción de mayor impacto]
```

**Etapas:** 0-39 = Fundación; 40-69 = Construido; 70-89 = Compuesto; 90-100 = Autónomo.
